# ICO Fairy — конвертер иконок

Конвертирует PNG, JPG и другие изображения в .ico прямо в браузере.
До 20 файлов за раз, выбор размеров (16–256px), скачивание одним кликом.
Файлы не покидают браузер — всё работает локально.

**Технологии:** HTML, CSS, JavaScript (Canvas API, File API, Drag & Drop)

**Смотреть:** https://minakmin29-tech.github.io/ICO-Fairy/
